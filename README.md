# Shibil Muhamed V — Portfolio

Personal portfolio site: education, work experience, projects, and contact.

Built with React, TypeScript, Vite, Tailwind CSS, Three.js (via React Three Fiber), and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

Profile, education, experience, and project data live in `src/data/portfolio.ts`.
Replace `public/cv/shibil-muhamed-cv.pdf` with the real CV/resume file.
